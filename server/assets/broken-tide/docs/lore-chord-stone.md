# Lore: The Chord Stone

The chord stone is a palm-sized shard of green glass recovered from the drowned bell tower of Solen.

The chord stone erases the last hour from the memory of whoever carries it.

Only the archivists know how to handle the stone safely. They keep it in a lead-lined box in the Old Archive.

The walk from the Lighthouse to the Harbor takes about forty minutes along the causeway.
